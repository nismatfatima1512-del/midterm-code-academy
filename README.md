## Questions & Answers

### 1. Which HTML elements did you use to structure the website?

I used semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` to organize the website. I also used headings, paragraphs, links, images, and lists to display the content clearly.

### 2. How did you arrange the course cards?

I arranged the six course cards using **CSS Grid**. On larger screens, the cards appear in three columns. I used `gap` to create equal spacing between them and highlighted one card as the most popular course.

### 3. Which CSS property was most useful?

The `display: grid` property was the most useful because it helped me create clean and organized layouts. I also used `grid-template-columns` to control the number of columns and arrange the cards properly.

### 4. What problem did you face, and how did you solve it?

One challenge I faced was making the About and Contact sections fit properly on smaller screens. I worked on adjusting their widths, spacing, and layout so that the content would not overflow the mobile screen.

### 5. How did you make the website responsive?

I used **CSS media queries** at different screen sizes, especially 1024px and 768px. I changed the grid layouts from three columns to two columns and then to one column on smaller screens. This helps the website adjust to desktops, tablets, and mobile phones.
